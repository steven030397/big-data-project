\begin{abstract}
This study investigates how crash frequency, severity, and type vary by time of day, day of week, and season, and how these patterns differ between urban and rural areas in Victoria. Using a comprehensive dataset of 187,018 crashes, we employ exploratory data analysis, statistical testing, and machine learning methods with advanced class imbalance handling (SMOTE resampling, class weights, and threshold optimization via Precision-Recall curves) to identify high-risk periods and environmental factors. Results reveal significant differences between urban and rural crash patterns, with rural areas experiencing fatal crash rates approximately four times higher than urban areas (4.10\% vs 1.01\%). Night/late night periods and Friday emerge as the highest risk temporal periods, particularly in rural areas. Machine learning models achieve 91.64-98.37\% accuracy, with Logistic Regression achieving the best sensitivity (35.59\%) and F1 score (0.127), while Random Forest (main) achieves the highest accuracy (94.38\%) and specificity (95.68\%). The rural-specific model achieves the highest precision (12.09\%), demonstrating that fatal crash patterns are more distinguishable in rural contexts. However, sensitivity remains limited (3.21\%-35.59\%) due to extreme class imbalance (1.66\% fatal rate), reflecting the inherent challenge of predicting rare fatal events while balancing precision and recall.
\end{abstract}

\section{Introduction}

\subsection{Background}
Road traffic crashes represent a significant public health concern, causing substantial mortality and morbidity worldwide. Understanding the temporal and geographic patterns of crashes is crucial for developing effective prevention strategies and resource allocation. Previous research has identified differences in crash characteristics between urban and rural settings, but comprehensive analysis of temporal patterns across these contexts remains limited.

\subsection{Research Objectives}
This project aims to:
\begin{enumerate}
    \item Investigate how crash frequency, severity, and type vary by time of day, day of week, and season
    \item Compare crash patterns between urban and rural areas in Victoria
    \item Identify high-risk periods and environmental factors associated with severe crashes
    \item Develop predictive models for crash severity using statistical and machine learning methods
\end{enumerate}

\subsection{Research Question}
How do crash frequency, severity, and type vary by time of day, day of week, and season, and how do these patterns differ between urban and rural areas in Victoria?

\section{Data Description}

\subsection{Dataset Overview}
The analysis utilizes crash data from Victoria, Australia, comprising 187,018 recorded accidents. The dataset includes information from multiple related tables:

\begin{itemize}
    \item \textbf{accident}: Primary crash data with 188,006 records containing temporal, severity, and crash type information
    \item \textbf{node}: Geographic classification data providing urban/rural categorization
    \item \textbf{person}: Person-level severity information for 438,984 individuals
    \item \textbf{atmospheric\_cond}: Environmental condition data for 190,417 records
    \item \textbf{road\_surface\_cond}: Road surface condition data
\end{itemize}

\subsection{Data Preprocessing}
The raw data underwent comprehensive cleaning and preparation:
\begin{itemize}
    \item Date and time parsing from character strings
    \item Factor conversion for categorical variables
    \item Missing data handling and imputation where appropriate
    \item Creation of derived variables (hour groups, season, area type classification)
    \item Data joining across multiple tables using accident identifiers
\end{itemize}

\subsection{Key Variables}
\begin{itemize}
    \item \textbf{Temporal}: Time of day (hour, hour groups), day of week, season
    \item \textbf{Geographic}: Area type (Urban/Rural classification)
    \item \textbf{Severity}: Numeric severity codes (1=Fatal accident, 2=Serious injury accident, 3=Other injury accident, 4=Non injury accident)
    \item \textbf{Crash Type}: Categorical accident type descriptions
    \item \textbf{Environmental}: Atmospheric conditions, road surface conditions
    \item \textbf{Traffic}: Speed zone, number of vehicles
\end{itemize}

\subsection{Exploratory Data Analysis}

Statistical testing employed:

\subsection{Machine Learning Analysis}

\subsubsection{Model Selection and Rationale}
Machine learning approaches were selected based on interpretability, computational efficiency, and suitability for imbalanced classification:
\begin{itemize}
    \item \textbf{Logistic Regression}: Chosen for interpretability and ability to handle class imbalance through threshold tuning. Coefficients provide direct insight into risk factors.
    \item \textbf{Random Forest}: Selected for its robustness to outliers, ability to capture non-linear relationships, and built-in feature importance measures. Particularly effective when combined with class weights for imbalanced data.
    \item \textbf{Multi-class Severity Classification}: Random Forest employed to predict four severity categories (Fatal accident, Serious injury accident, Other injury accident, Non injury accident), allowing comprehensive severity analysis beyond binary classification.
\end{itemize}

\subsubsection{Data Splitting Strategy}
A 70/30 train/test split was employed with the following justification:
\begin{itemize}
    \item \textbf{Sample Size Consideration}: With 187,018 total crashes, a 70\% training set provides $\sim$130,000 samples, sufficient for robust model training while maintaining a large independent test set ($\sim$56,000 samples) for reliable performance evaluation.
    \item \textbf{Class Distribution Preservation}: The split naturally preserves the 1.66\% fatal crash rate in both training and test sets, ensuring realistic performance estimates.
    \item \textbf{Reproducibility}: Random seed (1234) ensures reproducible splits across runs.
\end{itemize}

\subsubsection{Class Imbalance Handling Strategy}
The dataset exhibits severe class imbalance (1.66\% fatal crashes), which poses significant challenges for standard classification algorithms. Two complementary approaches were implemented:

\textbf{1. Threshold Optimization (Logistic Regression)}
\begin{itemize}
    \item \textbf{Why Threshold Tuning?}: Logistic regression outputs probabilities, allowing flexible threshold adjustment. The default 0.5 threshold is inappropriate for imbalanced data, as it maximizes accuracy (which favors the majority class).
    \item \textbf{Precision-Recall Curve for Threshold Selection}: The optimal threshold was selected using a Precision-Recall (PR) curve on the \textbf{training set predictions} (not using cross-validation for threshold selection). This ensures the test set remains truly independent.
    \item \textbf{F1 Score as Optimization Metric}: The threshold was optimized to maximize F1 score (harmonic mean of precision and recall) via the PR curve, for the following reasons:
    \begin{itemize}
        \item \textbf{Imbalanced Data Focus}: PR curves are more informative than ROC curves for severely imbalanced data, as they focus on the minority class performance rather than overall discriminative ability.
        \item \textbf{Balance}: F1 score balances precision and recall, making it appropriate for imbalanced data where both metrics matter.
        \item \textbf{Direct Optimization}: PR curves allow direct optimization of the precision-recall trade-off, which is more relevant than sensitivity-specificity when dealing with rare events.
    \end{itemize}
    \item \textbf{Threshold Search Range}: Thresholds from 0.01 to 0.99 were evaluated in 0.01 increments (99 thresholds), providing fine-grained optimization across the full probability range.
\end{itemize}

\textbf{2. SMOTE Resampling (Random Forest)}
\begin{itemize}
    \item \textbf{Why SMOTE?}: Random Forest benefits from balanced training data to learn better decision boundaries for rare events. SMOTE (Synthetic Minority Oversampling Technique) creates synthetic samples of the minority class during cross-validation, ensuring the model sees balanced data in each fold.
    \item \textbf{SMOTE in Cross-Validation}: SMOTE is applied inside each CV fold to the training portion only, ensuring no data leakage. This creates balanced training data for each fold while maintaining realistic validation sets.
    \item \textbf{Class Weights with SMOTE}: Class weights are also applied in conjunction with SMOTE. Weights are calculated as $w_i = \frac{N}{2 \times n_i}$ where $N$ is total samples and $n_i$ is samples in class $i$, but calculated on the SMOTE-balanced data to further emphasize rare events.
    \item \textbf{Threshold Optimization on Validation Holdout}: After hyperparameter selection via CV, a 20\% validation holdout is created from the original (imbalanced) training data. The final model is retrained with SMOTE, then threshold is optimized on this imbalanced validation holdout using PR curve (maximizing F1). This prevents overfitting to SMOTE-balanced distributions and ensures realistic threshold selection.
\end{itemize}

\subsubsection{Cross-Validation Protocol}
\begin{itemize}
    \item \textbf{Stratified 5-Fold Cross-Validation}: Selected as a balance between statistical reliability and computational efficiency. Five folds provide sufficient variance reduction while maintaining reasonable computational time. Folds are created using stratified sampling (via \texttt{createFolds}) to ensure class distribution is preserved across folds.
    \item \textbf{Grid Search for Hyperparameters}: During CV, a grid search is performed over hyperparameter combinations:
    \begin{itemize}
        \item \textbf{mtry}: [3, 5, 7] - Number of variables randomly sampled at each split
        \item \textbf{ntree}: [100, 200] - Number of trees in the forest
    \end{itemize}
    For each parameter combination, 5-fold CV is performed with SMOTE, and mean CV F1 score is used to select the best parameters.
    \item \textbf{PR Curve Threshold Optimization}: Within each CV fold, after training with SMOTE, predictions on the validation fold are used to find an optimal threshold via PR curve (maximizing F1). The final threshold is then optimized on a separate validation holdout (20\% of training data) from the original imbalanced distribution to ensure realistic threshold selection.
\end{itemize}

\subsubsection{Separate Urban vs Rural Models}
Separate models were trained for urban and rural crashes with the following justification:
\begin{itemize}
    \item \textbf{Different Risk Patterns}: Statistical analysis revealed substantial differences in crash patterns between urban and rural areas (4$\times$ higher fatal rate in rural areas), suggesting distinct underlying risk mechanisms.
    \item \textbf{Feature Importance Differences}: Area-specific models allow different risk factors to emerge (e.g., speed zones may be more predictive in rural contexts, while traffic density matters more in urban settings).
    \item \textbf{Better Generalization}: Models trained on area-specific data can better capture local patterns without interference from contrasting patterns in other contexts.
    \item \textbf{Practical Utility}: Separate models enable targeted interventions and policy recommendations specific to each area type.
\end{itemize}

\subsubsection{Evaluation Metrics}
Comprehensive metrics were calculated to fully assess model performance:
\begin{itemize}
    \item \textbf{Accuracy}: Overall classification correctness (may be misleading with imbalance)
    \item \textbf{Sensitivity (Recall)}: Proportion of actual fatal crashes correctly identified (critical for safety applications)
    \item \textbf{Specificity}: Proportion of non-fatal crashes correctly identified (important for avoiding false alarms)
    \item \textbf{Precision}: Proportion of predicted fatal crashes that are actually fatal (important for resource allocation)
    \item \textbf{F1 Score}: Harmonic mean of precision and recall
    \item \textbf{ROC AUC}: Area under ROC curve, measuring overall discriminative ability
\end{itemize}
These metrics together provide a comprehensive view, as focusing solely on accuracy would mask the models' ability to identify rare fatal events.

\section{Machine Learning Analysis}

\subsection{Class Imbalance Considerations}
The dataset exhibits severe class imbalance with only 1.66\% of crashes being fatal (98.34\% non-fatal). This imbalance presents fundamental challenges:

\begin{itemize}
    \item \textbf{Default Models Fail}: Standard algorithms predict all crashes as non-fatal, achieving 98\% accuracy while identifying zero fatal crashes.
    \item \textbf{Metric Selection Critical}: Accuracy alone is meaningless; sensitivity (ability to catch fatal crashes) becomes paramount for safety applications.
    \item \textbf{Threshold Selection Essential}: The default 0.5 probability threshold is inappropriate, as it maximizes accuracy (favoring majority class) rather than balancing class-specific performance.
\end{itemize}

\subsubsection{Implementation Details}

\textbf{Logistic Regression Approach}:
\begin{itemize}
    \item \textbf{Method}: Precision-Recall (PR) curve on training set to find threshold maximizing F1 score
    \item \textbf{Justification}: F1 score balances precision and recall, making it more appropriate for imbalanced data than accuracy. PR curves are more informative than ROC curves when dealing with severe class imbalance.
    \item \textbf{Result}: Optimal threshold typically ranges from 0.01 to 0.10 (much lower than default 0.5), reflecting the need to lower the decision boundary to catch rare fatal events
\end{itemize}

\textbf{Random Forest Approach}:
\begin{itemize}
    \item \textbf{Method}: Stratified 5-fold cross-validation with SMOTE resampling, grid search for hyperparameter tuning (mtry, ntree), and PR-curve threshold optimization on validation holdout
    \item \textbf{Justification}: SMOTE (Synthetic Minority Oversampling Technique) creates synthetic samples of the minority class during cross-validation, ensuring the model sees balanced data in each fold. Grid search finds optimal hyperparameters (mtry = 3, ntree = 100) via cross-validation. Threshold is optimized on a validation holdout from the original (imbalanced) training data to ensure realistic performance estimates.
    \item \textbf{Result}: The SMOTE pipeline successfully balances classes during training, while threshold optimization on imbalanced validation data prevents overfitting to balanced distributions. Best hyperparameters selected via 5-fold CV with F1 score as the optimization metric.
    \item \textbf{Additional Details}: After selecting best hyperparameters via CV, the final model is retrained on the full training set with SMOTE, then threshold is optimized using PR curve on a 20\% validation holdout from the original imbalanced data.
\end{itemize}

\textbf{Why Different Approaches?}
\begin{itemize}
    \item Logistic regression naturally outputs calibrated probabilities, making PR-curve threshold optimization straightforward on training data
    \item Random Forest benefits from SMOTE during training to expose the algorithm to balanced data in each CV fold, helping it learn better decision boundaries for rare events
    \item Both models use threshold optimization, but RF optimizes on a validation holdout to prevent overfitting to SMOTE-balanced data
    \item This approach leverages each algorithm's strengths: LR's calibrated probabilities vs RF's non-linear interactions learned from balanced training data
\end{itemize}

\section{Results and Discussion}

\subsection{Key Findings}

\subsubsection{Urban vs Rural Differences}
The analysis reveals substantial differences between urban and rural crash patterns:
\begin{itemize}
    \item Rural areas experience fatal crash rates approximately 4 times higher than urban areas (4.10\% vs 1.01\%)
    \item Rural areas show higher proportions of serious injuries across all temporal periods
    \item Crash type distributions differ significantly, with rural areas showing more diverse crash scenarios
\end{itemize}

\subsubsection{Temporal Patterns}
Clear temporal patterns emerge:
\begin{itemize}
    \item Afternoon rush hours (15-18) show highest absolute crash frequencies
    \item Night/late night hours show highest fatal crash rates, particularly in rural areas
    \item Friday consistently shows highest crash frequencies and fatal rates
    \item Seasonal variations are present but relatively minor compared to daily and hourly patterns
\end{itemize}

\subsubsection{Risk Factors}
Machine learning analysis identified key risk factors:
\begin{enumerate}
    \item Accident type (especially pedestrian collisions)
    \item Speed zone (higher speeds associated with increased fatal risk)
    \item Area type (rural location is a strong predictor)
    \item Time period (night/late night highest risk)
    \item Number of vehicles involved
\end{enumerate}

\subsection{Limitations}
Several limitations should be acknowledged:
\begin{itemize}
    \item Class imbalance in fatal crashes (1.66\%) significantly affects model performance, resulting in low precision despite good sensitivity
    \item Missing data in environmental factors required filtering
    \item Temporal resolution limited by available data granularity
    \item Geographic classification may not capture all urban/rural nuances
    \item Potential confounding factors not captured in the dataset
\end{itemize}

\section{Conclusions}

This comprehensive analysis reveals significant temporal and geographic patterns in crash data from Victoria. Key conclusions include:

\begin{enumerate}
    \item \textbf{Geographic Disparity}: Rural areas face substantially higher fatal crash rates (4x higher odds), indicating a critical need for targeted interventions in rural settings.
    
    \item \textbf{High-Risk Periods}: Night/late night hours, particularly on Fridays during spring, represent the highest risk combinations, especially in rural areas.
    
    \item \textbf{Key Risk Factors}: Accident type (especially pedestrian collisions), speed zone, and area type emerge as the most important predictors of fatal outcomes.
    
    \item \textbf{Model Utility}: Machine learning models with SMOTE resampling, class weights, and threshold optimization demonstrate varying performance profiles. The logistic regression model achieves the best sensitivity (35.59\%) and F1 score (0.127) with good overall balance (91.64\% accuracy, AUC = 0.783). The Random Forest (main) model achieves the highest accuracy (94.38\%) and specificity (95.68\%). The rural-specific model achieves the highest precision (12.09\%), demonstrating that fatal crash patterns are more distinguishable in rural contexts where fatal crashes are more common. The urban model achieves very high accuracy (98.37\%) and specificity (99.39\%) but extremely low sensitivity (3.21\%), reflecting the challenge of predicting extremely rare events. All models provide actionable insights into risk factor prioritization, though sensitivity remains limited by the extreme class imbalance (1.66\% fatal rate).
    
    \item \textbf{Policy Implications}: Results suggest that interventions should focus on:
    \begin{itemize}
        \item Rural road safety improvements
        \item Night-time driving safety measures
        \item Speed management, particularly in higher speed zones
        \item Pedestrian safety initiatives
    \end{itemize}
\end{enumerate}
